# 8. Self-improving skill

**What it shows:** The tests fail until you know two setup quirks. Devin works them out, adds the feature, and writes a repo skill so later sessions set up correctly.

**Starter repo:** [devin-demo-self-improving-skill](https://github.com/thequantexplorer/devin-demo-self-improving-skill)

**Needs:** GitHub only

Setup steps are in the starter's [DEVIN_DEMO.md](https://github.com/thequantexplorer/devin-demo-self-improving-skill/blob/main/DEVIN_DEMO.md).

## Prompt

```text
Add a "weekly_revenue" report to https://github.com/<you>/devin-demo-self-improving-skill, mirroring daily_revenue (same column schema pipeline, snapshot test, CLI flag).

This repo has a couple of non-obvious quirks that trip up newcomers (generated code and how tests depend on the environment). When you hit them, don't just work around them: once you've solved it, write a repo skill at .agents/skills/acme-reports-dev/SKILL.md capturing exactly how to set up, run, and test this repo correctly, so the next session gets it right the first time. Open a PR with the feature, the green test run, and the skill.
```

## Presenter notes (spoilers)

What Devin should find, so you can narrate it. Keep this out of the starter repo so Devin finds it on its own.

- Quirks: the columns come from code generated by `npm run codegen` off `schema.json`, and the snapshot tests only pass with `TZ=America/Chicago`. Both are documented only in `.github/workflows/ci.yml`.
- Follow-up: after merging, start a fresh session with a similar task (e.g. "add monthly_refunds") and show it reading the skill and passing first time.
